# AI Green Skills

**AI Green Skills (AGS)** are structured skills for AI agents (GitHub Copilot, Claude, ChatGPT, Cursor…) that enable them to design and develop more sustainable software, following the green software engineering principles of [Creedengo](https://green-code-initiative.org).

> A growing share of code is now generated by AI. Without dedicated instructions, these agents ignore eco-design best practices. AGS fills that gap.

---

## Repository structure

```
skills/
  SKILL_TEMPLATE.md                    # Template for creating a new skill
  SKILL_green_code_review.md           # Detect Creedengo green code rule violations
  SKILL_build_rgesn_evidence.md        # Build an RGESN self-assessment evidence dossier
  SKILL_review_frugal_ai.md            # Review AI/ML/LLM features for frugality
  SKILL_contribute_creedengo_rule.md   # Create or review Creedengo rule contributions
```

---

## What is a skill?

A **skill** is a Markdown instruction file given to an AI agent. It defines:

- **What to do** — the task to accomplish
- **How to reason** — the steps to follow, in order
- **Where to look** — the authoritative references (e.g. [`creedengo-rules-specifications`](https://github.com/green-code-initiative/creedengo-rules-specifications))
- **What to produce** — the exact format of the output
- **What never to do** — hard constraints

---

## Usage

1. Open the desired skill file (e.g. `skills/SKILL_green_code_review.md`).
2. Paste it as a system prompt or instruction into your AI agent.
3. Provide the relevant input: source code, repository, product documentation, architecture notes,
   RGESN scope, or rule idea depending on the selected skill.

---

## Creating a new skill

Copy `skills/SKILL_TEMPLATE.md`, fill in every section (`[placeholder]`), and name the file following the convention:

```
SKILL_<verb>_<subject>.md
```

Examples: `SKILL_review_rule_spec.md`, `SKILL_implement_rule.md`

See [`skills/README.md`](skills/README.md) for the full guide.
