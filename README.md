# AI Green Skills

**AI Green Skills (AGS)** are structured skills for AI agents (GitHub Copilot, Claude, ChatGPT, Cursor…) 
that enable them to design and develop more sustainable software, 
following the green software engineering principles of several reliable and acknowleded sources 
(such as [Creedengo](https://green-code-initiative.org), or [RGESN](https://ecoresponsable.numerique.gouv.fr/publications/referentiel-general-ecoconception/)).

### Why skills for sustainable software?

> A growing share of code is now generated by AI. Without dedicated instructions, these agents ignore eco-design best practices. AGS were created to fill that gap.

Creedengo maintains a growing catalog of green code rules across multiple languages, while RGESN
defines a broader eco-design reference framework for french digital services. 
On the other side, skills allow any AI agent to assist contributors and developers consistently, without 
hallucinating rules, criteria, or evidence, and always pointing back to authoritative sources.
The aim of AGS is to integrate both concepts into a single harmonious system, enabling agents to keep a **frugal AI mindset**.

## What is a skill?

A **skill** is a Markdown instruction file given to an AI agent. It defines:

- **What to do** — the task to accomplish
- **How to reason** — the steps to follow, in order
- **Where to look** — the authoritative references (e.g. [`creedengo-rules-specifications`](https://github.com/green-code-initiative/creedengo-rules-specifications))
- **What to produce** — the exact format of the output
- **What not to do** — immovables constraints

A skill is not code. It is a **contract between a human and an AI agent**, written in plain
Markdown so it is readable by both.

---

## Usage

1. Fetch the desired skill file from this repository (e.g. `skills/SKILL_green_code_review.md`).
2. Paste it as an internal skill to feed your own AI agent in your `.skills/` folder
3. Use your coding agent as usual. The agent now respects the rules the skill covers.

---

## Creating a new skill

Copy `skills/SKILL_TEMPLATE.md`, fill in every section (`[placeholder]`), and name the file following the convention:

```
SKILL_<verb>_<subject>.md
```

Examples: `SKILL_review_rule_spec.md`, `SKILL_implement_rule.md`

See [`skills/README.md`](skills/README.md) for the full guide.
